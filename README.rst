========================================
    るみのシンプルな画像ビュワー
========================================
| るみが作ったシンプルな画像ビュワーでつ、名をRSIVと申す。
| GPU UIでレンダリングします。
|
| 軽量で、使いやすく、シンプルなことを目指しています。

対応形式
==========
順番は実装順

* PNG
* JPEG
* GIF(静止画/アニメーション)
* WebP(静止画/アニメーション)
* MAG(YJKモード/200ラインモードは非対応)
* MAKI(200ラインモードは非対応)
* BMP(RLE圧縮、1bpp、OS/2形式対応)
* PI
* SVG(ラスターに変換します)

インストール方法
===================

Linux
-------
| シェルで ``install_linux.sh`` をする
| 「シェルスクリプト？なにそれきっしょ」って人は
| シェルスクリプトを読んで手動でインストールすることもできます。

使い方
=========
| STEP1. アプリを開く
| STEP2. 画像をドラドロ
| STEP3. おめでとう、貴様は画像を開くことに成功しました！

キー操作
==========
| 開発者がエロ画像を見る際、マウスの位置ときゅうりを持つ手の位置が干渉することが合ったため、
| RSIVでは全部キーボードで完結し、そしてほぼスペースキー周辺で完結します。

* X							リセット
* M							メニュー
* ← / c						画像を左に移動
* → / b						画像を右に移動
* ↑ / f						画像を上に移動
* ↓ / v						画像を下に移動
* Ctrl + ↑ / Alt + f		画像を上に移動
* Ctrl + ↓ / Alt + f		画像を下に移動
* <							次の画像
* >							前の画像
