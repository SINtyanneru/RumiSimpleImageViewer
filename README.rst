========================================
    るみのシンプルな画像ビュワー
========================================
| るみが作ったシンプルな画像ビュワーでつ。
| GPU UIでレンダリングします。
|
| 軽量で、使いやすく、シンプルなことを目指しています。

対応形式
==========
* PNG
* JPEG
* GIF(静止画/アニメーション)
* WebP(静止画/アニメーション)
* MAG(YJKモード/200ラインモードは非対応)
* MAKI(200ラインモードは非対応)

使い方
=========
| STEP1. アプリを開く
| STEP2. 画像をドラドロ
| STEP3. おめでとう、貴様は画像を開くことに成功しました！
